Database architecture

The system will use PostgreSQL as the primary relational database, with Redis for caching and session management. A read replica will be provisioned in the same region to handle analytics queries without impacting write performance. Connection pooling via PgBouncer is recommended to prevent connection exhaustion under sustained load.

02
Auth Claude led, ChatGPT concurred

Authentication strategy

JWT-based authentication with a 15-minute access token expiry and rotating refresh tokens stored in httpOnly cookies. OAuth2 for third-party providers. Rate limiting at the auth endpoint: 10 attempts per minute per IP with exponential backoff after the 5th attempt.

API design

RESTful API with versioning via URL prefix /v1/. All endpoints return a consistent envelope: { data, error, meta }. OpenAPI spec generated from code annotations. GraphQL evaluated and explicitly deferred — unnecessary complexity for the current scope.
